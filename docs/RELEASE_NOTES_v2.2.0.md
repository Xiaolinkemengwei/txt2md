# AI eye 2.2.0 发布说明

**发布日期**：2026-11-07  
**重点**：扫描件的图表不再变乱码 · 图片可直接识别 · 结果可在软件内查看复制

---

## 这一版解决什么问题

2.1 的 OCR 能认出扫描书的字，但**认不出「这行字属于图」**。一本书里的 K 线图，
纵轴刻度（`3.60` `2.80` `2.40`）、气泡标注（`突破` `放量`）、图例说明全被当成正文
行，成段堆在段落中间——读起来就是乱码。

实测样本（275 页扫描版 PDF，每页为整页位图）：

| 页面 | OCR 总行数 | 其中图内碎片 |
|---|---|---|
| 第 41 页 | 27 | 8 |
| 第 21 页 | 31 | 14 |
| 第 61 页 | 43 | 25 |

2.2 先在页面上把「图」找出来，图里的字不进正文，图本身裁出来保留。

## 一、图表还原

### 怎么找到图

OCR 每行都带四点框，这本身就是一份**免费的文字掩膜**。把掩膜从页面暗像素里
减掉，剩下的连通结构就是图形；再做形态学连块与尺寸过滤，就得到图区。

没有引入版面检测模型：docling / layoutparser 走 torch，模型加运行时 800 MB ~ 1.5 GB，
会毁掉单文件 exe 的体积；DocLayout-YOLO 的 ONNX 版 25~40 MB 且是 AGPL，与 MIT 冲突。
现有 opencv + numpy 已随 OCR 安装，**零新增依赖**。

### 效果

第 41 页转换后：

```
![图2-13上升旗形图例](sample_assets/sample_p041_fig1.png)

个股在上涨途中经过旗形整理后，股价将维持原来的趋势…
```

- 图区里的 8 行刻度与标注**不再出现**在正文里
- 图按原位置裁切，与前后段落交错排列，阅读顺序不乱
- 图注自动挂到图上，正文里不再重复一遍
- 孤立页码（`31`）自动剔除

### 安全边界

- **整页图**（封面、整版图录）：剔除后剩余文字不足三成时不剔除任何文字——宁可带点
  噪声，也不能让一页内容凭空消失
- **检不出图**：行为与 2.1 完全一致，不会更差
- **单张裁切失败**：跳过该图，整页照常输出
- **不想要图**：`--no-images`；**想关掉切分**：`--no-layout`

## 二、图片识别

`png / jpg / jpeg / webp / bmp / tif / tiff` 可以直接当输入：

```bash
aieye 截图.png --to md          # 识别 → Markdown
aieye 票据.jpg --to docx        # 识别 → Word（原图一并嵌入）
```

- **OCR 自动开启**：图片没有文字层，这不是可选项
- 小于 1500px 宽的图先放大再识别（截图常见 800px，直接识别精度差）
- 手机照片按 EXIF 方向校正
- 原图按内容选编码：线稿/截图用 256 色 PNG，照片用 JPEG
- 图片里的图表同样做版面处理，刻度不会混进正文

`image` 只能作为**输入**：`--to image` 会直接报错并列出可用目标。

## 三、结果查看器

转换完成后**双击记录**打开：

- **两个视图**：Markdown 原文 / 纯文本
- **复制全部**、**复制选中**（框选后只复制选区）
- **另存为**：md / txt / html / docx / pdf / xlsx / csv，七个目标都支持
- **打开文件**：直接用系统默认程序打开产物
- 预览在转换时顺带缓存（上限 2 MB，保留最近 20 条），所以 docx / pdf 这类
  二进制产物也能看到并复制文字，不重复读盘

「在文件夹中显示」移到记录右键菜单。

## 四、插图输出到各格式

| 目标 | 处理 |
|---|---|
| md | 写入 `<输出名>_assets/`，文中 `![题注](目录/文件名)` |
| html | `<figure><img><figcaption>` |
| docx | 嵌入正文，居中 + 斜体题注 |
| pdf | 随 HTML 打印一并嵌入 |
| txt | 保留 `【图】题注` 占位 |
| xlsx / csv | 只留题注行 |

无插图的任务**不创建**空的素材目录；纯文字转换的结果与 2.1 **逐字节一致**。

## 升级提示

- 旧版本生成的 Markdown 不受影响；新版本只在**扫描件 OCR** 与**图片输入**时产生素材目录
- 打包版已内置 OCR 与版面分析，无需额外安装
- 源码安装：`pip install "aieye[ocr]"`

## 已知限制

- 双栏页面（如目录页）仍按单栏从上到下读取，左右栏会交错
- 每页重复的页眉文字（`第 2 章 形态买入图谱`）仍会进正文，只剔除了页码
- 表格被识别为「表格区域」后同样裁成图片，尚未还原成真正的表格行列
