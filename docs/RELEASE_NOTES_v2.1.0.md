# AI eye 2.1.0 发布说明

> 一眼看懂，一键转好。项目更名为 **AI eye**，界面按 Windows 11 Fluent 设计规范重做，
> 并修掉了三处会让「转换看起来没反应」的缺陷。

## 下载什么

| 文件 | 适用 |
|---|---|
| **`AIeye-2.1.0-win64.zip`** | Windows 用户，解压双击 `AIeye.exe` 即可，**不需要安装 Python** |
| `aieye-2.1.0-py3-none-any.whl` | 已有 Python 环境，`pip install` 后可用 `aieye` 命令 |
| `aieye-2.1.0.tar.gz` | 想读源码或二次开发 |

下载后可用 `SHA256SUMS.txt` 核对完整性：

```powershell
Get-FileHash .\AIeye-2.1.0-win64.zip -Algorithm SHA256
```

## 这一版最重要的三件事

### 1. 转换不会再「点了没反应」

之前如果转换线程里出现未预期的异常，线程会静默结束、结束信号永远发不出来，
界面就停在「转换中…」——按钮灰着、进度条不动，只能杀进程重开。现在：

- 单条任务异常只记该条失败，其余照常继续
- 结束信号放在 `finally` 里，任何情况下都会发出，界面一定恢复可用
- 预检阶段的文件系统异常（网络盘掉线、路径非法、权限被回收）也不再穿透到线程外

### 2. 窗口拖到最小不再吃掉一整行选项

「覆盖同名文件」这一行原先在窗口压到最小时会被静默裁掉（Qt 不会报错，只是不画）。
现在按布局真实下限锁定最小尺寸，测试里也加了对应断言，防止回归。

### 3. 全部跳过时给了出口

目标文件都已存在时，转换记录区右上角会出现「覆盖并重转」，点一下即覆盖旧文件重跑，
不必自己去下面找开关。

## 界面：Windows 11 风格

- **设计令牌统一**：字号阶 26/20/14/13/12/11，圆角阶 卡片 8 / 控件 4 / 胶囊，
  语义色「前景 + 浅底」成对使用；所有控件的悬停、按下、聚焦、禁用状态都补齐了
- **应用栏**：眼睛图标 + 产品名 + 版本标签 + 本机引擎摘要 + 关于入口
- **格式卡片**：选中态是「浅蓝底 + 蓝描边 + 角标勾」，比整块高饱和底色更轻；
  不可用的格式置灰并写明原因
- **转换记录**：悬停高亮，**双击任意记录即可在资源管理器里定位输出文件**
- **空状态**：与应用图标同源的眼睛线稿，文案直接说下一步该做什么
- **拖放**：文件拖进窗口时出现虚线强调框，提示「松开即可添加」
- **记忆**：输出格式与三个开关会记住上次的选择
- **快捷键**：`Ctrl+O` 选文件 · `Ctrl+Shift+O` 选文件夹 · `Ctrl+Enter` 转换 · `F5` 重新扫描

图标也换成了与名字呼应的眼睛图形（同时对应 OCR 识别扫描件这项能力）。

## 更名说明

| 旧 | 新 |
|---|---|
| 项目名 `txt2md` | **AI eye** |
| `txt2md.py` | `aieye.py` |
| `txt2md.spec` | `aieye.spec` |
| `txt2md.exe` | `AIeye.exe` |
| `pip install txt2md` | `pip install aieye` |
| 命令 `txt2md` | 命令 `aieye`（旧名仍作为别名保留） |

**兼容性**：命令行旧名 `txt2md` 继续可用；xlsx 中转用的 `_txt2md_body` 工作表
（2.0 生成的文件）仍能被正确读回。GitHub 仓库地址未变，因此文档里的仓库链接仍是旧路径。

## 升级建议

- 从 2.0 升级：直接替换 exe 即可，配置文件会自动沿用
- 从 1.0 升级：命令行用法完全兼容，`aieye note.txt` 依旧输出 `note.md`，
  `--plain` 依旧逐字保真，排版算法与 1.0 字节级一致

## 已知限制

- 图形界面仅亮色主题，未跟随系统深色模式
- PDF 读取只取文本层；扫描件需勾选 OCR，识别文字可能有误
- PDF 输出是文本重排，不是原文档版式复刻
- `docx` 不保留分栏、页眉页脚、脚注、批注与内嵌图片
- 仅提供 Windows 打包产物；macOS / Linux 从源码运行
